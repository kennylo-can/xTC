# xTC Gatekeeper Guide

## English

If macOS says xTC cannot be opened because it is from an unidentified developer, use one of these methods:

1. In Finder, Control-click `xTC.app` and choose `Open`.
2. Or open `System Settings > Privacy & Security` and click `Open Anyway`.
3. If prompted again, confirm with your password or Touch ID.

This is the normal macOS Gatekeeper flow for unsigned apps.

## 中文

如果 macOS 提示 xTC 无法打开，因为它来自未知开发者，可以用下面两种方式之一：

1. 在 Finder 里按住 `Control` 点击 `xTC.app`，选择 `打开`。
2. 或者进入 `系统设置 > 隐私与安全性`，点击 `仍要打开`。
3. 如果再次弹窗，按提示输入密码或使用 Touch ID 确认。

这就是未签名应用在 macOS 上的正常 Gatekeeper 处理方式。
